# Roadmap

这份路线图用于控制范围，不是待办竞赛。每一阶段完成后先使用、测试和重构，再进入下一阶段。

## 阶段 1：阅读文章

- [ ] 设计文章表
- [ ] 学习并选择数据库迁移工具
- [ ] 实现已发布文章列表 API
- [ ] 实现文章详情 API
- [ ] 在 Web 端展示文章列表与详情

完成标准：不用直接操作数据库，也能新增一条测试数据并在页面读到它。

## 阶段 2：管理文章

- [ ] 管理员登录和 Session
- [ ] 路由权限中间件
- [ ] 新建、编辑、删除草稿
- [ ] 发布与撤回文章
- [ ] Markdown 编辑与预览

完成标准：未登录用户无法调用任何修改接口。

## 阶段 3：游客评论

- [ ] 评论数据模型
- [ ] 游客提交评论
- [ ] 输入清理、限流与审核状态
- [ ] 管理端审核和删除评论

完成标准：游客提交的内容默认不可公开，管理员审核后才显示。

## 以后再考虑

- 图片与对象存储
- 全文搜索
- Redis 缓存
- 文章版本历史
- 数据统计与可观测性
